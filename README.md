# SchoolAI

SchoolAI — мектеп сабактарына жасалма интеллект менен презентация түзүүчү онлайн сервис.

## SchoolAI эмне кылат?

SchoolAI мугалимдерге жана окуучуларга сабак үчүн презентацияларды тез даярдоого жардам берет.

Предметти, классты, сабактын темасын жана слайддардын санын тандасаңыз, AI презентациянын мазмунун автоматтык түрдө түзөт.
